# 地理、模型与镜头连续性

## 建立空间

- 选与航线相交的少数街区。建筑顶面、地面、河岸和道路要能在同一张平面图上叠合。区分离地高度、绝对海拔、楼层数和房屋基底高度。地势起伏大时，从地形采样每栋楼的底标高，桥梁和高架再单列标高。
- 数据优先用本地测绘／开放城市模型。对 WGS84 小范围轮廓，配套转换器输出东、北米数。Three.js 中用 X 向东、Y 向上、负 Z 向北。近似投影适合本地街区，跨城区和高纬大范围优先使用当地投影，保留单位和反算原点。孔洞保留为庭院，MultiPolygon 按部件导入。用一段已知街宽验证尺度和方向。
- 为镜头建立三个细节层次。天际线靠高低轮廓、屋顶剪影和大尺度亮暗。中景靠街墙连续性和窗层节奏。近景靠凹进去的门窗、檐口厚度、室内层次和磨损。对共享建筑复用轮廓、楼层、窗色与朝向。远处分层时保持稳定 ID、材质随机种子和投影尺度，切换可做迟滞或过渡带。
- 若同一格窗左右明暗破碎，固定第一个有问题的帧，逐面 ID 用 flat 插值传给片元着色器，随机值按整格坐标计算，再做同帧对照。对单帧内部的盐粒应先修着色器。加长快门还会把它拖成运动噪点。

## 搭地标和街角

- 在正面轮廓和明显侧面各选一个约束机位。钟塔看檐口退台与表盘，山寺看山脊上的屋顶层次，现代车站看屋盖、柱距与候车人的尺度。手绘地标可以先建可信几何，将正面画稿用 UV 固定到模型。侧背补材质分区，再绕拍检查轮廓、笔触滑动和露底。
- 人眼会追踪的部分用几何控制，细密重复的信息可烘成贴图。书架、海报、搪瓷招牌适合贴图，柜框、玻璃厚度、檐棚和灯具更适合建模。选一小段街面做材质样板，把屋顶、店面和远处窗光放进同一次曝光中调节。近景参考图上天空的颜色也要一起比较。
- 占道穿模从平面解决。给车体加方向与长度，转弯时扫过整块碰撞轮廓。人行道按通行净宽留出家具和柱子。对结尾被挡的荧幕、塔钟或山门，把四角投到屏幕并沿视线检查最近遮挡物。重复查看实际运动路径两侧几帧。

## 把镜头接起来

- 从远景就让接近的街口有可追踪的标志。分别渲染远近场时，用同一参照物对齐相机位置、比例、朝向、焦距与深度遮挡。用建筑边沿遮住细节交接，先查突然显现的整栋楼、透明度开关、图层切换和自动曝光跳变。
- 定相机时同时画眼点、目标点和期望主体宽度。在等时间间隔的关键帧之间计算屏幕速度。经过弯道或贴近前景时，按弧长或显式速度曲线重定时。快速平移造成的近景爆冲可以通过退开机位、降低局部速度和缩短快门来调整。
- 路口平面构图需要正交时，可以固定一个对焦平面的可见宽度，连续降低透视投影中深度对画幅的影响。透视端满足可见宽度与距离、视场角的关系，正交端保持相同宽度，再插值机位和倾角。用两个不同深度的窗框检验过渡有没有抽动。
- 循环要让画面、速度和可见的动态状态共同衔接。可以闭合路线，也可让片尾荧幕、橱窗或车窗填满画面，接回同一开场构图。播放从最后两秒到前两秒。把最后一帧和第一帧之间的移动量，与邻近正常帧间移动量一起看。片长为 N 帧时只导出索引 0 到 N−1。

## 按场景选择天气与运动

- 滨水镜头中，让船的水线驱动局部几何位移和法线扰动。用岸灯倒影观察船首推水和尾流。泡沫的亮度独立控制。雨丝、落点与水面环纹共享位置和时间。按深度遮雨，雨丝已形成曝光轨迹时可在多子帧合成后单独绘制一次。
- 内陆城市可以把精力放在自行车、轨道车、树影或天棚上。轨道车转弯先验轮轨关系与车体扫掠范围。树影要和光源、地面及风向一致。给每次运动稳定的种子和相位，使预览、抽帧和分段重渲落在同一时刻。
