# 把自己的城市拍成一支三维短片

拿一张路线草图，把开头、最贴近观众的一刻、结尾画在上面。泉州可以从骑楼檐口下穿过，顺着店面的灯回到街口。山城可以从坡顶看到轻轨，再沿台阶落到同一座桥下。选哪条路线，取决于当地人从哪里认出家。

| 阶段 | 具体产出 | 进入下一步前，怎样判断 |
|---|---|---|
| 选记忆 | 写下城市、街区、一件当地人会做的事、希望观众离开时记住的画面。放入有来源的地标正侧面、一个普通街角、一次真实时段的光线参考。 | 让熟悉这里的人看去掉地名的构图。他从哪里认出这是这里？如果只认出一座著名建筑，补一个日常空间线索。 |
| 定地理 | 选主路线覆盖的街区，建筑底面、道路、岸线或地形共用当地原点与米制坐标。登记楼高依据。把地理压缩记在路线图中。 | 从高处和路面各截一帧。标记同一屋角、塔尖或路口。两帧中的左右关系能对上。没有实测的高度单独标注。 |
| 先走一遍 | 用体块、主角占位物和一条完整相机路径，导出低分辨率原速短片。标出入街、主角掠过和回到开头的位置。 | 给人看一次原速。他能指出自己从哪里来、正往哪里去。过渡处逐帧检查遮挡、视差和画面速度。 |
| 做代表画面 | 把地标近景、普通店面和远近交替处做到目标质量。优先做轮廓、真实构造、材质粗糙度与照明，再加小物。估算真正占屏的像素。 | 三张图并排看像同一晚或同一天。同一栋楼在远景和近景有可辨认的对应物，人物和车辆能在净空内通过。 |
| 做运动与声音 | 行人、车辆、灯影和天气共用影片时钟。用已选音乐的重音安排主要动作。循环片先试听尾接头，再看音画连播。 | 从最忙的 2–4 秒原速片段，可以看清主体。窗格没有反复闪灭，运动物体没有双边，接缝前没有突然混入另一段乐句。 |
| 锁片并交付 | 做一段目标画质试渲，估算耗时和峰值磁盘占用，再分段导出全片。交付影片、可编辑包、真实来源与重开方法。 | 解码检查帧数、色彩和时长。把包解压到新目录，断开旧项目依赖，重渲代表帧。若换过配乐，复核新包实际导出的也是最后确认的声音。 |

### 可以直接抄用的委托

> 我的城市是「城市／街区」。我最熟悉的是「一件日常的小事」，最想保留「一个地点或一种光线」。希望做「时长、画幅」，给「观看场景」使用。现有材料是「照片／地理数据／可用录音」。请先交路线草图、一段原速灰模和三个代表机位，让我判断它像不像这里，再精修成片。

接受修改意见时，保留上一版已认可的机位和色调。若反馈是“街景和远景不统一”，用相同机位试改同一段外墙、窗光或遮挡，解释哪一种改动解决了问题。重新设计整个街区会造成新的比较变量。

### 把工具交给下一位创作者

从发布页下载 `city-film-studio.zip`。在 Claude 网页版中，打开 Customize → Skills 上传这个 ZIP 并启用。在本地项目中，把 ZIP 内的整个 `city-film-studio` 文件夹解压到下表目录。完成后打开制作项目，在新会话里使用上面的委托。[下载页](https://github.com/Haao-sys/city-film-studio/releases/latest)

| 工具 | 项目内的上级目录 | 如何开始 |
|---|---|---|
| Claude Code | `.claude/skills/` | 输入 `/city-film-studio`，后接城市和街区 |
| Google Antigravity | `.agents/skills/` | App 或 CLI 输入 `/city-film-studio`；独立 IDE 在 Customizations 确认技能后，直接描述委托 |
| Codex | `.agents/skills/` | 输入 `$city-film-studio`，后接城市和街区 |

手工制作时，打开包里的 `references/run.md`。示例工程和工具在 `assets/starter/` 与 `scripts/`。完整渲染需要可运行 Chromium、WebGL 2 和 FFmpeg 的环境。
